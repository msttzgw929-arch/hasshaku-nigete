# 八尺様からにげて！

お腹がとっても大きい八尺様から、夜の町を逃げ回る一人称3Dゲーム（ホラーコメディ）です。ブラウザだけで動きます。

## 起動のしかた
ES Modules を使っているので、ローカルサーバー経由で開いてください（index.html のダブルクリックでは動きません）。
```
cd hasshaku-game
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```
three.js は `vendor/` に同梱しています（CDN 不要・オフラインで動きます）。

## 操作
- 画面上のバーチャルスティック（スマホでもPCのマウスでも使えます）
  - **左スティック**：移動
  - **右スティック**：すばやく振り向く（左右）・見上げる（上下）
- 捕まったら：画面を**タップ / クリック連打**（スペースキーでもOK）でお腹をペチペチ → 脱出
- キーボード（おまけ）：WASD・矢印キーで移動、←→で振り向き、Q/Eで見上げる、スペースで連打。PCではスティック以外をマウスでドラッグしても視点を動かせます。

## ルール
- 八尺様の足は**いつもプレイヤーより遅い**です（最高でもプレイヤーの65%。どんなに大きくなっても同じ）。
- 捕まえられないと**イライラ度**がたまり、満タンになるたびに**お腹レベル**が上がってお腹が大きくなります（上限なし）。
- お腹レベル2以上になると、お腹にぶつかった建物はこわれて崩れます（街灯や自販機はレベル1でも倒れます）。
- 捕まると拘束されます。制限時間内にお腹を必要な回数たたけば脱出（最初は11回くらい・かんたん）。脱出できないとゲームオーバー。
- 逃げ切った時間がスコアです（ベスト記録はブラウザに保存）。

## しくみ
- **八尺様の絵**：もらった1枚絵から背景を切り抜き（rembg の isnet + u2net ＋ GrabCut でスカートまで補完）、
  「下半身（スカート）」「お腹」「上半身（頭・胸・腕）」「顔の表情」の4レイヤーに分けて、カメラに向くビルボードとして重ねています。
  - お腹だけがバネ物理でぷるんと揺れます（足音・たたかれた時・建物に当たった時・巨大化時）。頂点シェーダーで変形しています。
  - スカートは歩くテンポに合わせて、左右の膝が交互に布を押し、すそが持ち上がるように変形します（体の上下動・傾きつき）。
  - お腹の巨大化もシェーダーで変形しています。巨大になると上半身ごと持ち上がり、お腹は地面に乗ってつぶれます。
  - 表情：元の絵の目と口をインペイントで消してから描き直した差分（にっこり／イライラ／激怒／痛がり／大喜び、各「口パク」版、まばたき）を作り、なめらかにクロスフェードしています。ボイスの音量に合わせて口が動きます。左上に顔のアップも表示します。
- **ボイス**：AivisSpeech Engine（Style-Bert-VITS2 系、ローカル実行）の感情スタイル付き女性モデル「F2」で、セリフごとに感情スタイル（幸せ・怒り・驚き・悲しみ・嫌悪）・抑揚・速さを変えて31本を事前生成（各セリフ3〜6テイクから音声認識で一番正確なものを自動選択）。`assets/voice/`。
- **効果音・環境音**：足音、ビンタ、崩壊音、心音、風・ドローンは Web Audio でリアルタイム合成。
- **町**：7×7ブロックの手続き生成（路地・家・店・アパート・看板・街灯・自販機）。がれきはインスタンス描画の簡易物理。
